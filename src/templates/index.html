🖼️ 图片

（读取中…）
提醒带图片
封面/头像随消息一起发，关掉则纯文字
内嵌：图就在卡片里，只有一条消息（图片由开放平台下载转存，不需要域名报备）。单独发一条：走富媒体（msg_type=7），图在文字上方且只能 1 张，代价是图是单独一条消息
图片尺寸提示
内嵌图片必须带 ![#宽px #高px](url)，否则手机端看不到图（电脑端却正常）
宽是上限，高填 0 表示按原图比例自动算（竖图、方图才不会被拉成 16:9）；高填了具体数就固定用它。原图比上限小则不放大。客户端只拿它预留空间，不是真的缩图。改完立即生效，不用重启
长图（比如 672×2225）整体等比压小到这个高度，比例不变、只是变小，免得手机上要滑好几屏。填 0 表示完全不限制
一条动态/评论有多张图时怎么排。固定方框（推荐）：每格都是一样大的正方形，发的是原图——外面看着是方格、点开是完整原图；比例不够方时按裁剪填充处理：保持原图比例放大到铺满方框、多出来的部分裁掉，不会拉伸变形、也不会补白边。原比例：也是原图，但高度跟着原图走、各格高度不齐。图床裁剪：让图床真裁成小方图，最整齐，代价是点开看到的也是那张裁过的图。⚠️ 裁剪的取景位置（竖图取上/中、横图取中）由客户端决定，markdown 只能给"方框多大 + 图片地址"，无法指定裁哪一块——如果你手机上看到的是被拉变形的，说明该客户端是拉伸而非裁剪填充，改选图床裁剪即可。⚠️ markdown 图片是块级、一行一张，做不到真正的 3×3 并排方阵
多图时每格的尺寸：原比例模式下是统一宽度（高度按原图算）；方块模式下是边长。单图不受影响，仍按原图比例。填 0 = 多图也跟单图一样按「提示尺寸-宽」走
一条动态/评论可能带多张图。填 0 = 全都发（动态最多 9 张）；嫌消息太长就填 3 或 4。多张图之间只换行、不空行
