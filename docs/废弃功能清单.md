## 清单

| 功能 | 移除于 | 为什么废了 |
|---|---|---|
| @全体成员 / `at_all` | v1.18.0 | 需要群主权限，走不通；改走私聊推送更实际 |
| 群名备注 | v1.19.0 | 群名改为官方接口自动获取，不需要手动备注入库 |
| 超管名单 `super_admins` / `admin_only` | v1.20.0 | 改为只认群主/管理员（后来这一条也废了，见下条） |
| **权限判定：群主/管理员** | 事实废弃 | 官方「获取群成员」接口是**内邀白名单制**，没有申请入口，普通开发者拿不到；`member_role` 字段取不到 → 谁都用不了，包括群主本人。机器人已不在群里做交互，权限判定也没了意义 |
| 群内指令（订阅/退订/列表/帮助/检测/我的ID） | v1.21.0 | 功能全部移到网页面板，机器人本体不做交互 |
| 指令面板 / 自定义菜单 | v1.21.0 | 同上（官方文档里的"创建指令面板"属于这套，不要照抄回来） |
| 报备链接 / 消息 URL 配置 | v1.21.0 | 图片走富媒体（msg_type=7），本地直传或平台拉取，都不需要报备域名 |
| 群级专属文案（第三层） | v1.30.1 | 层级简化为：内置默认 → 全局 → UP主 → 合集。群级那层已摊到各 UP 主 |
| 桌面版（Electron / `desktop.py`） | v1.92.0 | 面板直接用浏览器打开即可，套壳没有必要；相关启动 bat 一并删除 |

内置默认 → 全局设置 → UP主专属 → 合集专属
